# Audio Player

The audio player on the Musical Notes page lets you listen to Marcelle's recordings.

## Controls

- **Play/Pause** - Click the large button to start or pause playback
- **Progress Bar** - Shows current position; click to seek
- **Time Display** - Shows current time and total duration

## Playlist

Click any track in the playlist to start playing it. The currently playing track
is highlighted.
