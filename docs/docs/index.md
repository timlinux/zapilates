# Zapilates Documentation

Welcome to the documentation for Zapilates, the official website of
Marcelle Sutton — Pilates instructor and researcher based in Lisbon
and Marvão, Portugal.

## About the Site

Zapilates is a Hugo-powered static website featuring:

- **The Method**: The Pilates method and the principles underlying it
- **Classes**: Private, group, barre, and remedial sessions
- **Specialisms**: Pilates for singers, dancers, and musicians
- **Research**: MMus (*cum laude*) thesis on Pilates warm-ups for classical singers
- **Journal**: Long-form writing on movement, breath, and the nervous system

## Technology Stack

- **Hugo** - Static site generator
- **SCSS** - Styling (compiled via Hugo Pipes with Dart Sass)
- **Vanilla JS** - Interactivity (no frameworks)
- **Nix** - Reproducible build and deployment
- **GitHub Pages** - Documentation hosting
