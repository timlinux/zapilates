# Navigation

## Main Menu

The main navigation is located in the header. On desktop, dropdown menus reveal
subsections. On mobile, tap the hamburger icon to open the navigation overlay.

## Sections

| Section | Content |
|---------|---------|
| About | Marcelle's biography |
| Classical Singing | Performances, music, videos |
| Pilates | Services and information |
| Buy Classes | Online booking |
| Contact | Get in touch |

## Mobile Navigation

On smaller screens:

1. Tap the hamburger icon (☰) in the header
2. The navigation overlay slides in from the left
3. Tap section headings to expand dropdowns
4. Tap links to navigate
5. Tap outside or the X to close
