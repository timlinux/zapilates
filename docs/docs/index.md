## About the Site

Canto Lyrico is a Hugo-powered static website featuring:

- **Classical Singing**: Performance archive, music recordings, and videos
- **Pilates Studio**: Services, classes, and online booking
- **E-commerce**: Stripe-powered class booking

## Technology Stack

- **Hugo** - Static site generator
- **SCSS** - Styling
- **Vanilla JS** - Interactivity
- **Stripe** - Payment processing
- **GitHub Pages** - Hosting
