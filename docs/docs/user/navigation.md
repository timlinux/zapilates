# Navigation

## Main Menu

The main navigation is located in the header. On mobile, tap the hamburger
icon to open the navigation menu.

## Mobile Navigation

On smaller screens:

1. Tap the hamburger icon (☰) in the header
2. The navigation menu opens
3. Tap links to navigate
4. Tap the icon again or press Escape to close
